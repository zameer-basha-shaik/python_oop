## Project

### CLI ContactBook

I also built a simple command-line Contact Book to practice the OOP concepts I learned.

Each contact is stored as a `Contact` object with:

- Name
- Phone
- Email

The ContactBook allows me to:

- Add contacts
- View contacts
- Search contacts
- Update contacts
- Delete contacts
- Validate contact details
- Store contacts in a JSON file

This project helped me understand how OOP concepts can be used in a small practical application instead of just writing separate examples.
